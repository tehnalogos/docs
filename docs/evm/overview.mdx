# LUKSO for EVM Builders

ERC standards made token and wallet interoperability possible, but production apps often need more than the original interfaces provide: richer metadata, safer receiving behavior, asset discovery, scoped permissions, gasless execution, account recovery, vault isolation, extensibility, and portable social data.

LUKSO standards address these gaps with Universal Profiles, LSP digital assets, ERC725Y metadata, receiver hooks, Key Manager permissions, relay calls, Vaults, contract extensions, and onchain social graph primitives.

Use this section to understand where common ERC and smart-account patterns start to break down, how LUKSO approaches the same design space, and which standards, contracts, recipes, and migration guides to use next.
